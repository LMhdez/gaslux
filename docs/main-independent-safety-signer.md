# Independent Safety signing worker (staging only)

The worker is not deployed and does not itself evaluate semantic safety. A separately administered Safety service/account must own its immutable reviewed code, persistent state, independent evaluation policy and private key. Do not install under the Integrator account or its root-equivalent host. Do not give the Integrator sudo, write access to this directory, key, policy, read token or signer journal. No credential is provisioned in this branch. No production key generated. Do not merge this isolated branch.

Fixed custody root /var/lib/gaslux-safety-signing (0700, Safety owner, trusted ancestors). Provision independently controlled Ed25519 key signer.pem (0600), dedicated least-privilege read-only GitHub token in read-token (0600), and owner-only policy.json atomically replaced by an independently authenticated evaluator. Policy schema gaslux-independent-safety-policy-v1 with decisions array of {head,evidence_sha256,decision}; exact digest per allowlisted PR and decision, no duplicate head. Policy is not a request input. Independently establish custody and pin public key fingerprint in a reviewed publisher release. First-time init-journal explicitly creates persistent database; sign refuses missing or key-drifted DB. Back up key/journal and protect against rollback; never recreate state after loss without independent incident review. Run as dedicated Safety owner with controlled PATH and environment. sign reads one bounded JSON {evidence,decision} via stdin, emits only signed receipt after durable commit. Approval independently rechecks live read-only snapshot and policy; signed historical withdrawal does not require live eligibility. The evaluator must actually assess safety; same-author comments or requester supplied policy must not auto-authorize. This is a bounded worker interface, not a network listener or an autonomous evaluator. Deployment and end-to-end validation are still pending.
