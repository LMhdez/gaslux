# Gaslux brand assets

This directory contains the original visual identity for the **Gaslux** project, independent of the Libertix banner. The design combines two connected paths in a G-shaped mark to represent Windows and Linux coexisting on a single computer.

| File | Purpose |
| --- | --- |
| [icon.svg](icon.svg) | Standalone square mark suitable for future icons and favicons |
| [logo.svg](logo.svg) | Horizontal Gaslux wordmark |
| [hero.svg](hero.svg) | README hero and source art for repository social preview |
| [workflow.svg](workflow.svg) | Target flow diagram (not a completed feature claim) |
| [distributions.svg](distributions.svg) | Six-distribution development status |
| [metadata.json](metadata.json) | Brand colors, title, description, topics and image references |

## Colors

- Background: `#0B1830`
- Cyan: `#48C7FF`
- Mint: `#57E7C7`
- Amber: `#FFB45A`
- Text: `#F1F9FE`

## GitHub repository metadata

Suggested **About** description (repository Settings / About):

> USB-free Linux dual-boot installer for Windows 10/11, with native distro backends and a recovery-first design. In development.

Suggested topics are listed in [metadata.json](metadata.json). These are suggestions, **not automatically configured on GitHub**. The share-card title comes from GitHub's repository metadata; this file cannot override it.

For the repository **Social preview**, use a 1280 × 640 PNG or JPEG exported from the [hero source](hero.svg), and upload it in GitHub's repository settings. The committed SVG does **not** automatically become the GitHub Open Graph preview image. Do not use a fake installed-system screenshot as a social preview.
