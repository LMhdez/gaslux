# Independent witness and authenticated Safety query — staging

Both logical SQLite journals are now checked against an independent monotonic checkpoint before use, and each state transition advances the witness by compare-and-swap before local COMMIT. A restored older DB disagrees with the witness and blocks authorization. Witness loss, timeout, rollback mismatch or crash between CAS and COMMIT blocks further operations; no automatic reset or reconciliation. An administrator must independently recover an interrupted checkpoint using preserved evidence. Witness state must be on a separately administered durable system outside BOTH rollback domains, with protected backup/restore and no client reset capability. The witness itself uses an append-only SQLite event history, not hardware monotonic storage; a privileged rollback of all three systems defeats it. Only the independent host administrator may initialize each role's genesis once. Fixed forced SSH commands bind signer/publisher roles to distinct SSH keys; client uses pinned host key, no agent/forwarding, no request-selectable endpoint. WITNESS_HOST and WITNESS_USER intentionally null until separately reviewed deployment. No live credentials provisioned. Publisher's genesis is digest of {schema:"gaslux-authority-checkpoint-v1",role:"publisher",repository_id:1460159259,pin:[],rows:[]}; signer init-journal emits its genesis. Never delete/reinitialize journal or witness after mismatch.

Signer query emits signed Ed25519 response bound to exact evidence, repository, head, fresh 256-bit nonce and current decision. Publisher verifies pinned public key, exact response shape, nonce and elapsed time; no cached approval. Signer checks independently witnessed journal and current policy under SQLite transaction. SSH client SafetyClient is implemented but endpoints intentionally null, no live publisher adapter. Configure independent host with forced query-only command to safety_signer.py query; separately authorize signing/evaluator input. Never give Integrator access to signer private key, policy or witness storage. A fresh query alone does not provide a distributed merge/revoke atomicity guarantee. Actual durable delivery, merge serialization across signer decision and GitHub merge, remote request settlement, independent semantic evaluator, additive gate and credential custody still require operational proof. No new PR/App, no authority published, production paused.
