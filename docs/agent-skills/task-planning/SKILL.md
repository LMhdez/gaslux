# Gaslux task-planning

Portable repository procedure. AGENTS.md, AI_POLICY.md and existing Safety gates remain authoritative. No new permissions.

1. Read live goal matrix, evidence registry, current dev and existing open/closed/merged PRs. #408 already enumerates 136 gate slots; do not recreate it.
2. Route by backend and first unmet gate; consult historical leads, known divergences and findings. Prefer reuse, reconciliation and remediation to redundant helpers.
3. Classify each task as scope review, existing PR pending, external evidence blocked or verified only by authorized verifier. Mark prerequisite gates and exact tests; distinguish a planning lead from code authorization.
4. Select only approved code scope. Do not turn a proposed task, skill or issue into write permission. Bound retries and move to other eligible tasks when blocked.
5. Document owner, dependencies, acceptance, exact references and updated status in the same intervention.
