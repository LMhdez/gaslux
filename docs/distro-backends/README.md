## Hierarquia das fontes
1. `release-config.json` **main**: apenas Mint 22.3/Zorin 18.1, com ISO, tamanho e SHA fixados; os valores aqui transcritos não substituem a validação do catálogo assinado.
2. [Arquitectura](https://github.com/LMhdez/gaslux/blob/dev/docs/ARCHITECTURE.md), [Plano multidistro](https://github.com/LMhdez/gaslux/blob/dev/docs/MULTIDISTRO_PLAN.md), [AGENTS](https://github.com/LMhdez/gaslux/blob/dev/AGENTS.md), [política IA](https://github.com/LMhdez/gaslux/blob/dev/AI_POLICY.md), [issue #3](https://github.com/LMhdez/gaslux/issues/3), [PR #7](https://github.com/LMhdez/gaslux/pull/7).
3. Páginas upstream listadas por distribuição (links a verificar contra a versão exacta); workflows de PRs podem estar desactualizados ou ter corridas posteriores. A data de referência deste inventário é 19-11-2026, não é uma verificação de todos os artefactos CI.
4. Não extrapolar um teste `SUCCESS` de um HEAD/fixture para outro. Verificar logs, SHA, anexos e evidência negativa antes de usar a etiqueta COMPROVADO.

## Ordem de execução segura
Consolidar regressões e first boot de Mint/Zorin; depois concluir handoff/instalação nativa de CachyOS; estudar/automatizar distinst de Pop!_OS; validar mídia/Calamares de Q4OS; finalmente instalação Atomic/deployment de Bazzite. A ordem ajusta-se apenas após comparação dos HEADs e evidências actuais.

## Regras da investigação
Esta PR documenta **contratos e hipóteses condicionais**. Não altera implementações, catálogo, schemas, boot ou firmware. Segurança e recuperação prevalecem sobre suportar mais distribuições. Falta de prova implica **PENDENTE/BLOQUEADO**, nunca parâmetro inventado.
